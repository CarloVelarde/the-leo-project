# Starlink Edu

Public education site for **Starlink-style LEO constellations**: page-by-page lessons, guided 3D lab, planned optional Python code-alongs.

Not affiliated with SpaceX. Pedagogical models only.

## Docs

`docs/` holds product context for when you need it—**not for every chat**. See [docs/README.md](docs/README.md) for when to open which file. Agents: [AGENTS.md](AGENTS.md).

## Quick start

```bash
npm install
npm run dev
npm run build
```

## Stack

Vite · React 19 · TypeScript · React Router · R3F · Tailwind v4 · pure TS in `src/sim/` · no backend.

## Core learning path

`/learn/:slug/:pageId` — Internet → GEO → LEO → ops → constellation → terminal → space network → synthesis. Optional tracks: orbit math, space safety, DTC.

## Stance

Conceptual main path; lab for intuition; optional ~15 min Python later. Trust via sources and model assumptions.
